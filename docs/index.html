Vivier

A desktop electronic pet that ages in real time and degrades if you ignore it. Everything below runs the same simulation core — no install, no build.

🐱 The pet, live Ages against your clock, survives a refresh. Feed / play / clean. Leave it and come back. 📈 Tuning viewer 30 days in one screen, four care patterns. Neglect kills it in six days; over-feeding kills it too. 👁 Glance test Can you name the pet's condition without reading the label? The question that decides the art.
